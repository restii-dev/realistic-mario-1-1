# Realistic Mario – Level 1-1 Inspired

A short prototype of a **realistic** take on classic Mario platforming.

Mario can actually die from head trauma when he hits bricks from below, and he drowns in water if he stays under too long.

> This is an **original level** loosely inspired by the spirit of Super Mario Bros. 1-1.  
> It is **not** a recreation or redistribution of Nintendo’s copyrighted level data, graphics, or music.

## Play in the browser (recommended)

Just open **[index.html](index.html)** locally or host the repo on GitHub Pages / any static host.

No install needed.

## Python / Pygame version

```bash
pip install -r requirements.txt
python realistic_mario_1_1.py
```

(The Python version auto-downloads the Realistic Mario sprite sheet from MFGG.)

## Features

- Headbonk death on brick blocks (realistic trauma)
- Oxygen meter + drowning in water sections
- Simple but satisfying platforming
- Works offline once loaded

## Controls

- Arrow keys / WASD – move  
- Space / W / Up – jump  
- R – restart after death
